# Pish Pish — Brand Identity

Premium minimalist logo system for a social experiences platform.

## The Mark: "The Pull"

An abstract convergence symbol where four outer nodes are drawn inward along curved trajectories toward a central focal point — the shared experience.

**Hidden reference:** The inward-scooping arcs abstract the beckoning "pish pish" gesture (calling something closer) without depicting any figure, animal, or literal illustration.

- **Electric Purple** `#6B21FF` — focal point, accent, tittles
- **Ink Black** `#0D0D0D` — arcs, nodes, wordmark
- **Pure White** `#FFFFFF` — primary background
- **Purple Mist** `#EDE5FF` — secondary UI tint
